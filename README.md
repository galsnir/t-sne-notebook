# t-SNE Notebook

Homework 1 (t-SNE) — Course 3945, 2025A.

This repository contains a Jupyter notebook implementing t-SNE for dimensionality reduction and visualization.

## Contents

- `t-SNE.ipynb` — main notebook with all exercises and results.

## Requirements

- Python 3.9+
- `numpy` >= 1.15.4
- `scikit-learn`
- `matplotlib`
- `jupyter`

Install with:

```bash
pip install -r requirements.txt
```

## Usage

```bash
jupyter notebook t-SNE.ipynb
```
